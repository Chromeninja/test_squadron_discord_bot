**Goal:** Fix all 5 action-required issues flagged in PR #255 code review, remove a stale artifact, and eliminate the `tickets.py` legacy ceiling by splitting the file below the 700-line modularity threshold.

**Architecture:** The project uses a backend-first layered architecture where all DB access must go through `backend/db/repository/*` classes — never `Database.get_connection()` directly in API routes. This PR introduced `backend/db/repository/tickets.py` (1 031 lines) and hardcoded it into the legacy ceilings, which defeats the modularity guardrail. All five review issues are in the same cluster of new files.

**Tech Stack:** Python 3.13, aiosqlite, FastAPI, pytest-asyncio, Ruff, mypy --strict (partial), `tools/check_modularity.py` pre-commit hook.

## Task 3: Fix f-string SQL in `tickets.py`

**Files:**
- Modify: `backend/db/repository/tickets.py:728-766`

`★ Insight ─────────────────────────────────────`
The WHERE clause here is programmer-controlled (no user data is interpolated), so there's no *actual* injection risk — but f-string SQL is still flagged by linters and reviewers because the pattern looks unsafe and can become a footgun if the variable is ever extended with user input. Concatenating the fixed-prefix query string directly avoids the pattern entirely.
`─────────────────────────────────────────────────`

- [ ] **Step 1: Locate both offending methods**

Read `backend/db/repository/tickets.py` lines 728-780.

- [ ] **Step 2: Fix `get_open_tickets`**

Replace:
```python
    async def get_open_tickets(
        self,
        guild_id: int,
        user_id: int | None = None,
    ) -> list[dict[str, object | None]]:
        """Return open tickets, optionally filtered by user."""
        where = "WHERE guild_id = ? AND status = 'open' AND deleted_at IS NULL"
        params: list[object] = [guild_id]
        if user_id is not None:
            where += " AND user_id = ?"
            params.append(user_id)

        async with Database.get_connection() as db:
            cursor = await db.execute(
                f"SELECT * FROM tickets {where} ORDER BY created_at DESC",
                tuple(params),
            )
            rows = await cursor.fetchall()
            return [dict(row) for row in rows]
```

With:
```python
    async def get_open_tickets(
        self,
        guild_id: int,
        user_id: int | None = None,
    ) -> list[dict[str, object | None]]:
        """Return open tickets, optionally filtered by user."""
        query = (
            "SELECT * FROM tickets"
            " WHERE guild_id = ? AND status = 'open' AND deleted_at IS NULL"
        )
        params: list[object] = [guild_id]
        if user_id is not None:
            query += " AND user_id = ?"
            params.append(user_id)
        query += " ORDER BY created_at DESC"

        async with Database.get_connection() as db:
            cursor = await db.execute(query, tuple(params))
            rows = await cursor.fetchall()
            return [dict(row) for row in rows]
```

`★ Insight ─────────────────────────────────────`
The backend-first rule is: API routes must never open a DB connection — they call a repository method. This keeps all SQL in one place, makes it testable in isolation, and means if the DB layer ever changes (e.g., migrate away from aiosqlite), only repository files need updating.

- [ ] **Step 1: Add `get_cooldown_reset` to TicketRepository**

In `backend/db/repository/tickets.py`, add this method to `TicketRepository` (place it near the other query helpers):

```python
    async def get_cooldown_reset(
        self,
        guild_id: int,
        user_id: int,
        global_reset_id: int = 0,
    ) -> int | None:
        """Return the most recent cooldown reset timestamp for the user.

        Checks both per-user resets and the global reset (user_id=0).
        Returns None if no reset record exists.
        """
        try:
            async with Database.get_connection() as db:
                cursor = await db.execute(
                    """
                    SELECT MAX(reset_at) FROM ticket_cooldown_resets
                    WHERE guild_id = ? AND user_id IN (?, ?)
                    """,
                    (guild_id, global_reset_id, user_id),
                )
                row = await cursor.fetchone()
            return int(row[0]) if row and row[0] is not None else None
        except Exception:
            return None
```
