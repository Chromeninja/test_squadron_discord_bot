# Support

Read the [README](README.md) and [setup guide](documents/SETUP.md) first, then
search existing issues and discussions. Remove tokens, API keys, session
values, user identifiers, and private logs before sharing information.

- Installation and configuration: open a discussion or issue with environment,
  deployment method, and redacted logs.
- Reproducible bugs: use the bug report template.
- Feature ideas: use the feature request template.
- Security vulnerabilities: follow [`SECURITY.md`](SECURITY.md), not a public
  issue.
- Conduct concerns: follow [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

Support is best-effort, with no guaranteed response time unless separately
agreed.
